# 民泊クイズ

民泊制度についてのクイズ（全10問）に答えると、点数に応じて名前入りの認定証イラストがその場で表示されます。

- 🏆 10点：民泊制度博士
- 🎓 8〜9点：民泊制度上級者
- 📚 5〜7点：民泊制度勉強家
- 🌱 0〜4点：民泊制度ビギナー

結果画像はダウンロードでき、Xでシェアするボタンも用意しています（#民泊クイズ）。

## 公開ページ

GitHub Pagesで公開しています。`index.html` を開くだけで動作します（サーバー不要）。

## ファイル構成

- `index.html` : クイズ本体（HTML/CSS/JS）
- `assets/images.js` : 4種類の認定証イラストをBase64化したデータ
- `認定証_*.png` : 認定証イラストの元画像
- `民泊クイズ.txt` : クイズ問題の原文
